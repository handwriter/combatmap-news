Версия **0.233.1**, upstream commit `61d1f407d93d2c786d493c1a53a2a8c9fb7aa663`.
MIT-лицензия сохранена в `admin/vendor/sveltia/LICENSE.txt`. Готовая сборка и SHA-256 её файлов

## Воспроизведение сборки

Нужны Node.js 24+ и pnpm **11.25.0**. Из корня репозитория:

```sh
node scripts/sveltia/rebuild.mjs
```

Скрипт загружает указанный immutable commit, проверяет и применяет `combatmap.patch`, устанавливает
зависимости по upstream `pnpm-lock.yaml` с `--frozen-lockfile --ignore-scripts` и выполняет сборку.
Временный каталог удаляется. В Git сохраняются ES-модуль CMS, его React DOM chunk и лицензия;
неиспользуемые IIFE/npm сборки и source maps не копируются. `COMBATMAP_PNPM` позволяет указать путь к pnpm.
Это отдельная операция; для обычной сборки сайта достаточно Node.js 20+ и npm.

## Расширение

`CMS.registerHistoryTemplate('collection/file', ReactComponent, { hidePreviewLinks: true })`
до `CMS.init()` заменяет штатную панель истории только указанного файла. Остальные формы остаются штатными.
Компонент получает:

- `entry` и `originalEntry`: Immutable Map текущей и сохранённой записи;
- `readonly`: доступность изменения;
- `getDraftData()`: свежая отделённая копия данных текущего черновика;
- `replaceDraft(data)`: синхронная замена данных черновика без сохранения.

Замена сохраняет исходную модель для диффа/отмены, использует штатный versioned value map и запрещена
после смены черновика или для readonly-записи. В предпросмотр дополнительно передаётся `originalEntry`.
Панель истории доступна также на безопасном `test-repo`, чтобы проверять восстановление без записей в GitHub.
Предпросмотр этих форм загружается через `srcdoc`, чтобы работать во встроенном браузере Codex.
Стили диффа подключаются только внутри предпросмотра test; остальные коллекции сохраняют штатный просмотр.

При обновлении upstream сначала проверить патч и эти контракты. Не заменять локальную сборку ссылкой на `latest`.
